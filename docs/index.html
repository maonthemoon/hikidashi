Windows用のランチャー

kaigiと打てば, 会議が開く.

日本語の名前は, ローマ字のまま探せます. もらったパスは, 貼れば開きます. 見つからなければ, そのままChatGPTへ. 日本語で仕事をする人のためのランチャーです.

動くデモ

日本語の仕事で, 手が止まらない

名前の一部を打って開くのは, どのランチャーも同じです. Hikidashiは, そのあいだに挟まる変換, 貼り直し, 探し直しを減らします.

変換しないで, 日本語の名前を探す

kaigiで「定例会議_議事録」, pawa-で「パワー」. ローマ字を辞書で漢字とかなに広げて探します. 窓を出すと日本語入力はオフになるので, 切り替えも要りません.

もらったパスを, 貼ってそのまま開く

メールやチャットのパスを貼ってEnter. 引用符が付いていても, /mnt/c/...でも, %APPDATA%\...でも開きます. BoxのファイルのURLは, 手元のファイルとして開きます.

見つからなければ, そのままChatGPTへ

いつものブラウザーのChatGPTに送るので, APIキーも追加の契約も要りません. 長い質問はShift+Enterで書く窓に変わり, 見出しや箇条書きを整えて見ながら書けます.

BoxもWSLも, 同じ入力欄で

bx でBox Drive, w でWSLのホームを探します. ふだんの一覧には混ざりません. Box Driveは手元のデータを読むので, 作者のPCでは約5万件を2秒以内に読み込みました.

アプリ, ChromeとEdgeのブックマーク, Windowsの設定, クリップボードの履歴, プロセスの終了も, 同じ入力欄です. すべての機能はマニュアルにあります.

電卓を開かず, RFまで

=と空白で計算のモードに入ります. Enterで結果をコピー. ふだんの検索には, 計算の行は出ません.

ほかのランチャーの列は, 2026年11月に公式の説明で確かめました. 「記載なし」は, 読んだ範囲に書かれていないという意味で, できないという意味ではありません. 版や, 入れた拡張によって変わります. 製品名は, それぞれの権利者のものです.

向いている人, 向いていない人

向いている

  • 日本語の名前のファイルを, 1日に何度も開く
  • メールやチャットで, パスやBoxのURLをよく受け取る
  • 調べものの多くを, ブラウザーのChatGPTで済ませる
  • WindowsとWSLを行き来する, 16進数やdBmをよく使う

向いていない

  • 拡張を店から探して, 機能を増やしたい
  • ファイルの中身まで探したい(名前だけを探します)
  • 窓の整列, 定型文, 通貨の換算もまとめたい
  • AIの答えを, ランチャーの窓の中で読みたい

試すのも, やめるのも簡単

置くだけで動く

exeは1つで約6MB. インストールも, 管理者権限も, アカウントも要りません.

待たせない

約1万6千ファイルの作者のPCでは, 1回の検索が1ms以下, 窓が出るまで約30ms, メモリは約20MBでした(2026年11月, 開発中の版).

使い方を送らない

自分から通信するのは, 同梱の辞書が見つからず, 取ってくるときだけ. 検索も学習も手元で済みます. 質問はブラウザーで開くだけです.

消せば終わり

自動起動を外して終了し, 置いたフォルダーと設定のフォルダーを消すだけです.

はじめかた

  1. ダウンロードReleasesからZIPを落として, 好きな場所に展開します.
  2. 起動Hikidashi.exeをダブルクリック. 署名がないので, 「PCが保護されました」と出たら「詳細情報」→「実行」.
  3. ホットキー使いたいキー(例: Alt+Space)を押して登録します.
  4. 打つホットキーを押し, 名前の一部を打ってEnter. kaigiから試してください.

Windows 10とWindows 11(64ビット)用です. いまのランチャーがAlt+Spaceを使っていても, 別のキーにすれば一緒に使えます. gitで入れる方法はREADMEに, 詳しい使い方とアンインストールはマニュアルにあります.

Windows用のランチャー

打って, 開く. 日本語の名前も.

ホットキーで入力欄を出し, 名前の一部を打ってEnter. アプリもファイルも, 貼ったパスも, ChatGPTへの質問も, 1つの入力欄から開けます.

ダウンロード → マニュアル

動くデモ

ブラウザーで再現したデモです

ほかのランチャーとの違い

スタートメニューの検索やPowerToys Runと同じ「打って開く」道具です. そのうえで, 日本語の環境で毎日使うときに困ることを減らしています.

日本語入力を切り替えずに, 日本語の名前を探す

kaigiと打てば「会議」の付く名前が出ます. ローマ字を辞書で漢字に広げて探すので, 変換は要りません. 窓を出すと日本語入力は自動でオフになります.

受け取ったパスを, 貼ってそのまま開く

引用符付きのパス, /mnt/c/..., \\wsl.localhost\..., %APPDATA%\...も, 貼ってEnterで開きます. BoxのファイルのURLは手元のファイルとして開きます.

見つからなければ, そのままChatGPTへ

一致がなければ, 打った文がChatGPTに送られます. ブラウザーを開いて入力欄に貼り直す必要はありません.

長い質問は, 整えて見ながら書く

Shift+Enterで書く窓が開きます. 見出し, 箇条書き, 太字, コードのMarkdownは印を隠して整えて見せるので, 送る前に読み返しやすくなります.

進数とRFの計算を, その場で

0x1Fで10進数と2進数, 10dBmでWと電圧, vswr 1.5でリターンロス, 10nH@2.4Gでリアクタンス. Enterで結果をコピーします.

軽い. exe 1つで動く

約4MBのexe 1つで, インストールも管理者権限も要りません. 作者のPC(約1万6千ファイル)では, メモリ約20MB, 1回の検索は1ms以下でした.

ほかに, ChromeとEdgeのブックマーク, Windowsの設定, Box Drive(bx ), WSLのホーム(w ), プロセスのkill(k )も同じ入力欄から使えます. 詳しくはマニュアル.

はじめかた

  1. ダウンロードReleasesからHikidashi-x.y.z.zipを落として展開します.
  2. 起動Hikidashi.exeをダブルクリック. 「PCが保護されました」と出たら「詳細情報」→「実行」.
  3. ホットキー使いたいキー(例: Alt+Space)を押せば準備完了です.

Windows 10, 11で動きます. gitで入れる方法, 更新, アンインストールはマニュアルにあります.

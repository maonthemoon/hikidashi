Hikidashi 0.1.0

Hikidashiのマニュアル

アプリ, ファイル, ブックマーク, 窓, プロセスを1つの入力欄から探して開く, Windows用のランチャーの使い方です.

Hikidashiとは

ホットキーで入力欄を出し, 名前の一部を打ってEnterを押すと開くランチャーです. アプリ, ファイルとフォルダー, ChromeとEdgeのブックマーク, 開いている窓, プロセス, Windowsの設定を, 1つの入力欄からまとめて探せます.

  • 飛び飛びの文字で探せる: pwptでPowerPoint, kaigiで「会議」の付くファイルが出ます.
  • パスを貼れば開く: メールやチャットで受け取ったパスを貼ってEnterを押すだけです. 引用符やWSLのパスも読めます.
  • 見つからなければChatGPTに聞く: 一致がないときは, 打った文字をそのままChatGPTに送れます.
  • 軽い: exe 1つで動き, 管理者権限は要りません. 50万件のファイルを数十msで探します.

インストール

インストーラーはありません. ZIPを展開して, Hikidashi.exeを起動するだけです. 管理者権限も要りません.

  1. ダウンロードReleasesからHikidashi-x.y.z.zipをダウンロードします.
  2. 展開と起動好きな場所に展開して, Hikidashi.exeをダブルクリックします.
  3. ホットキー使いたいキー(例: Alt+Space)を押して登録します.

ZIPの中は, Hikidashi.exe, ローマ字で日本語の名前を探すための辞書SKK-JISYO.Lとそのライセンス(SKK-JISYO.L-COPYING.txt), LICENSE.txt, THIRD-PARTY-NOTICES.txt, docs\manual.html(このマニュアル)です. 展開する前に, ZIPを右クリックして「プロパティ」を開き, 「許可する」にチェックを入れて「OK」を押すと, 初めて起動するときの警告が出にくくなります.

置いた場所のHikidashi.exeがそのまま動きます. 展開したフォルダーは消さずに残してください. 別の場所へ移すときは, フォルダーごと移して, もう一度起動します(自動起動の登録先も直ります).

動作環境はWindows 10とWindows 11です. 必要なものはWindowsに入っているものだけで, 追加のインストールは要りません.

gitで入れる場合

リポジトリをcloneして, 中のbin\Hikidashi.exeを起動するだけでも使えます. bin\Hikidashi.exeは最新のリリースと同じexeで, ビルドは要りません.

cd %USERPROFILE%
git clone https://github.com/maonthemoon/hikidashi.git

管理者として開いたコマンドプロンプトはC:\Windows\System32から始まり, そこではcloneできません. 普通に開くか, 先にcd %USERPROFILE%(PowerShellならcd $HOME)で自分のフォルダーに移ります.

初めて起動するとき

Hikidashiには署名がないので, 「WindowsによってPCが保護されました」(SmartScreen)と出ることがあります. 「詳細情報」を押して, 出てきた「実行」を押すと起動します.

「スマート アプリ コントロールが安全でない可能性のあるアプリをブロックしました」と出たときは, スマートアプリコントロールがオンのPCです. 署名のないexeは個別に許可できないため, Windowsセキュリティの「アプリとブラウザーコントロール」→「スマートアプリコントロールの設定」で「オフ」にします. 会社のPCで実行が禁止されている場合は, 管理者に確認してください.

ホットキーの登録

初めて起動すると, 窓が出てPress the hotkey you want to use, for example Alt+Spaceと聞かれます. 使いたいキーをそのまま押すと登録され, Hotkey set: Alt+Spaceのように出ます.

使えるキー例
Ctrl, Alt, Shift, Winのどれかと組み合わせたキーAlt+Space, Ctrl+Shift+K, Win+F1
単独で使えるキーF1〜F24, PrintScreen, Pause
  • 文字キーやSpaceなどは, 単独では登録できません. どのアプリでもそのキーが打てなくなるためです.
  • ほかのアプリが使っているキーを押すと, Alt+Space is used by another app. Try another key.と出ます. 別のキーを押すか, そのアプリの設定を変えます(PowerToysからAlt+Spaceを引き継ぐ).
  • Escを押すと, 登録せずにやめます. あとからタスクトレイのメニューのChange hotkey…で登録できます.

ホットキーがなくても, タスクトレイのアイコンをクリックすれば窓を出せます.

Windowsと一緒に起動

ホットキーを登録すると, 「Start Hikidashi when Windows starts?」と聞かれます. 「はい」にすると, Windowsにサインインしたときに自動でタスクトレイに常駐します.

あとから変えるときは, タスクトレイのメニューのStart with Windowsを押して, オンとオフを切り替えます. 登録先はユーザーごとのスタートアップ(レジストリのHKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run)なので, 管理者権限は要りません.

更新する

  1. タスクトレイのメニューのQuitで終了します(動いている間はexeを上書きできません).
  2. Releasesから新しいZIPをダウンロードして展開し, 古いものと置き換えます.
  3. 新しいHikidashi.exeをダブルクリックします.

設定, 学習, 入力の履歴はそのまま残ります. 終了せずに別のフォルダーの新しいexeを起動したときは, 動いている古いものが終わって入れ替わり, 窓の一番下にHikidashi was updatedと出ます.

gitで入れた場合は, Quitで終了し, git pullしてからbin\Hikidashi.exeをダブルクリックします. 前の版が%LOCALAPPDATA%\Hikidashiに写したexeは, 新しい版を起動すると終わって消えます.

探して開く

  1. ホットキーを押します. 窓が出て, 日本語入力はオフになります.
  2. 名前の一部を打ちます. 1文字打つごとに一覧が変わります.
  3. Enterで1行目を開きます. ほかの行は↑ ↓で選びます.

開いたら窓は隠れます. 次に出したときは前回の入力が全選択で残っているので, そのまま打てば上書き, Enterなら同じものをもう一度開けます.

一致のしかた

  • 飛び飛びでよい: 打った文字が名前にこの順で入っていれば一致します(pwpt→PowerPoint). 大文字と小文字, 全角と半角は区別しません.
  • 並び順: 名前の先頭で一致 > 単語の先頭で一致 > 続けて一致 > 飛び飛び, の順に上になります. 同じくらいなら短い名前, アプリ, フォルダー, ファイル, 設定の順です.
  • ローマ字で日本語: 英字を3文字以上打つと, ひらがな, カタカナ, 漢字にも広げて探します(kaigi→会議, pawa-→パワー). 打ちかけ(kaig)でも出ます.
  • 学習: 同じ文字を打って前に開いたものは1位に出ます. よく使うもの, 最近使ったものも少し上がります.
  • ファイルは2文字から: 1文字では件数が多すぎるので, ファイルとフォルダーは2文字目から探します(f で絞ったときは1文字から).

一覧の見かた

窓に見える一覧は8行です. 結果は50行まであり, 9行目からはホイールか↓でスクロールして見ます(右端に細い印が出ます). 1行目に名前(一致した文字は太字), 2行目に小さくパスなどが出ます. 右端の文字は種類です.

右端Enterで起きること
app起動する. 起動中ならその窓を前に出す
file, folder既定のアプリで開く. フォルダーはExplorerで開く
bookmarkそのブックマークのブラウザー(ChromeかEdge)で開く
windowその窓を前に出す
setting, systemWindowsの設定のページを開く, スリープなどの操作をする
kill確認なしにプロセスを終わらせる
copy計算の結果などをコピーする
ChatGPT打った文字をChatGPTに送る
run, urlコマンドのエイリアスを実行する, ページを開く

窓の一番下には, 索引を作っている間のIndexing your folder…や, エラー(赤)が出ます.

種類を絞る

先頭に1〜2文字と空白を打つと, その種類だけを探します. 入力欄の左にfileなどの印が出ます.

先頭探すもの例
a アプリa code
f ファイルとフォルダーf 議事録
b ChromeとEdgeのブックマークb 勤怠
k 終わらせるプロセスk excel
w WSLのホームのファイルとフォルダー(WSLはこのときだけ読む)w README
bx Boxのファイルとフォルダー(Boxはこのときだけ探す)bx 見積
g Googleで検索する(Enterで検索)g 明日の天気
c ChatGPTに聞く長い質問の窓をすぐ開く(長い質問)c
cb クリップボードの履歴(クリップボードの履歴)cb 見積
= 計算(計算)= 0x1F

入力欄が空のときにBackspaceを押すと, 印が消えて全部を探す状態に戻ります. プロセス, WSL, Boxは, 絞ったときだけ出ます. BoxとWSLはファイルが多く, ふだんの検索に混ぜると一覧が埋まるためです. 文字は設定のKeysで変えられます.

ファイルを条件で絞る

ファイルの名前と一緒に, 次の条件を打てます. 条件だけでも探せて, 新しい順に並びます.

打つもの絞り方
ext:pdf, ext:docx,xlsx拡張子
in:案件名前にその語を含むフォルダーの中
modified:7d7日以内に更新したもの(hは時間, dは日, wは週)

最近使ったもの

設定のSearchでShow recent itemsをオンにすると, 入力欄が空のときに, 最近開いたものが10件まで出ます. 初めはオフです.

ほかの窓をクリックしても隠れます. 速く打ってすぐEnterを押したときは, 今の入力の結果を最大0.3秒待ってから開くので, 1つ前の入力の結果が開くことはありません.

開き方を選ぶ

行を選んでTabを押すと, その行の開き方の一覧に変わります. ↑ ↓で選んでEnterで実行します. もう一度TabかEscで元の一覧に戻ります.

行の種類開き方

フォルダー初めはCopy file, Copy path, Copy WSL path
アプリ初めはOpen new window(起動中でも新しく起動), Open file location, Copy path, Run as administrator
ブックマークOpen, Copy URL
プロセスKill, Open file location, Copy path
設定Open, Run as administrator(コントロールパネルの項目だけ)
ChatGPTAsk ChatGPT, Search Google, Copy text

パスを貼って開く

入力欄にパスを貼ると, 検索せずにそのファイルかフォルダーの1行だけが出ます. Enterで開き, TabでOpen folderなどを選べます.

読める形例
WindowsのパスC:\Users\me\Documents\見積.xlsx, C:/Users/me/...
共有フォルダー\\server\share\資料
環境変数%USERPROFILE%\Downloads
ファイルのURLfile:///C:/Users/me/...
WSLのパス/mnt/c/Users/me/..., /home/me/..., ~/project
  • 前後の空白, 引用符(" ' 「」など), <>, 末尾の句読点は取ってから読みます. 複数行を貼ったときは1行目を使います.
  • ないパスは2行目にNot foundと出ます. 共有フォルダーとWSLのパスは, 届かないと待たされるので, あるかどうかを確かめずに出します.
  • WSLのフォルダーも, EnterではExplorerで開きます. ターミナルでそのフォルダーに入るときはAlt+Enterです(WSLの中のそのフォルダーに入ります).
  • BoxのWebのURL(https://….box.com/file/.... 社内のツールで作ったリンクもこの形)を貼ると, Box Driveの手元のファイルに引いて, ファイルの行を出します. EnterでExcelやPowerPointなど, いつものアプリで開きます. Box Driveにないときは, 2行目がNot found in Box Drive · Open in browserになり, ブラウザーで開きます.
  • Boxの共有リンク(https://….box.com/s/...)は, どのファイルか手元では分からないので, ブラウザーで開きます.
  • そのほかのhttps://で始まるURL(Boxの共有リンクなど)を貼ると, 2行目がOpen in browserの1行だけが出ます. Enterでブラウザーで開きます.

ChatGPT, Google, ブックマーク

  • ChatGPT: 一致が1つもないときは, 右端がChatGPTの1行だけが出ます. Enterでブラウザーにchatgpt.comを開き, 打った文字を入力欄に入れます. 5秒たってChatGPTの窓が前にあれば, HikidashiがEnterを押して送ります(ほかの窓が前にあるときは押しません). 一致があるときは, Shift+Enterで書く窓にしてからEnterで送れます.
  • Google: 先頭にg を打ってEnterか, Ctrl+Alt+Enterで, 打った文字をGoogleで検索します. Ctrl+Enterは, 一致があってもChatGPTに聞くキーです. どのキーに何をさせるかは, 設定のKeysで変えられます.
  • ブックマーク: ChromeとEdgeのブックマークを名前で探します(ある方だけ). 2行目の頭にChrome ·かEdge ·が出て, 開くとそのブラウザーで開きます. ブックマークを足したら, 次に窓を出したときに読み直します.

どれも, 初めはWindowsの既定のブラウザーで開きます. 設定のWebで, ChromeかEdgeに決めたり, 新しい窓で開くか新しいタブで開くかを選んだりできます. ChromeとEdgeは, そこで決めたプロフィールで開きます.

ChatGPTに自動で送られないときは, 設定のWebで, ChatGPTをCopy, then openにします. 打った文字をコピーしてChatGPTを開くので, 貼り付けて送ります.

長い質問

入力欄でShift+Enterを押すと改行され, 窓が下に伸びて何行も書けるようになります. 2行以上の文を貼ったときと, c を打ったときも同じです. 窓の上の帯にChatGPTの印が出るので, ChatGPTに送る窓だと分かります. 見出しや太字などのMarkdownは, Obsidianのように整えて見せます. カーソルのある行だけ**や#などの記号が見え, ほかの行では隠れます. 箇条書きは- を打った時点で「•」になり, 引用には縦線, チェックボックスには□が出ます.

キー起きること
EnterChatGPTに送る. 1行の質問と同じく, 開いたChatGPTの入力欄に入れてEnterを押します. とても長いとき(日本語でおよそ1,300字より長いとき)は貼り付けで入れます
Shift+Enter改行. 箇条書き(- , 1. , - [ ] , > )の行なら, 次の行に印が付きます. 印だけの行で押すと箇条書きを終えます
Tab, Shift+Tab箇条書きの行を字下げする, 戻す
Ctrl+B, Ctrl+I選んだ文字を太字(**), 斜体(*)にする
Ctrl+↑, Ctrl+↓前に送った文を新しい順に呼び出す(20件まで). 書く窓が空のときは↑だけでも呼び出せます
Esc検索に戻る. 書きかけは残り, 入力欄が空のときにShift+Enterで続きを開けます

ほかの窓をクリックして閉じたときは, 次に窓を出すと書きかけのまま開きます. 表は記号のまま並び, 画像, 数式, 図は出ません. ChatGPTには書いた文字(記号つき)をそのまま送ります. 貼り付けで入れたときは, 送ったあとクリップボードを元の中身に戻します. 記号を隠さず薄く見せたいときは, 設定のWebでhide Markdown marksのチェックを外します.

WSLのファイルを探す

w に続けて名前の一部を打つと, WSLのホームのファイルとフォルダーが出ます. 開き方はふだんのファイルと同じです. WSLの一覧は, 初めてw を打ったときと, 前に読んでから5分たっていたときに読み直します. 読んでいる間は一番下にReading WSL…と出て, 前の一覧で探せます. WSLを使わない日はWSLを起こしません.

プロセスを終わらせる

k に続けて名前を打つと, 終わらせるプロセスが出ます. Enterを押すと, 確認なしにすぐ終わらせます. 右端のkillがクレイ色なのは, この違いを示すためです.

  • 窓のあるプロセスは, 窓のタイトルで1行ずつ出ます. 同じプロセスがほかの窓も持っているときは, 2行目にAlso closes its other windowsと出ます.
  • 窓のないプロセスは, 名前ごとにまとめて出ます(chrome.exe ×20). Enterでまとめて全部を終わらせます.
  • 権限が足りないときは, UAC(管理者の確認)が出ます.
  • svchost.exeやexplorer.exeなど, Windowsの動作に欠かせないプロセスは出ません.

Windowsの設定と操作

Windowsの設定のページを, 英語と日本語の名前で探せます(display, ディスプレイ, 環境変数, bluetoothなど約60件). 右端はsettingです.

次の操作もできます. 右端はsystemです.

名前起きること
Lock画面をロックする
Sleepスリープする
Empty Recycle Binごみ箱を空にする
Restart, Shut down, Sign outEnterを2回押したときだけ実行する

Restart, Shut down, Sign outは, 1回目のEnterで行がPress Enter again to shut downのように変わります. もう一度Enterを押すと実行し, ほかのキーかEscでやめます.

計算

=と空白を打つと, 左にcalcの印が出て計算のモードになります. 続けて数や式を打つと, 結果が出ます. Enterで結果をコピーします. 何も打っていないときは, 使い方の例が出ます. ふだんの検索には, 計算の行は出ません.

四則演算もできます((12+3)*4. + - * / ^ ( ) %).

進数

16進数は0x, 2進数は0bを付けて打ち, 10進数は数字だけで打ちます. 打った進数以外の2つが出ます. 2進数は4桁ごとに区切って見せ, コピーは0b付きで区切りなしです. 16進数のコピーは0x付きです.

0b11101116進数, 10進数
1187(数字だけ)16進数, 2進数

vswr 10 il 2dBは, 部品の出力端から負荷を見たVSWRが10(リターンロス1.74dB)のとき, 損失2dBの部品(ケーブルやフィルターなど)の入力から見た値です. 部品そのものの反射はないとみなします. 反射は行きと帰りで損失を2回通るので, リターンロスが4dB良くなります. rlやgammaでも使えて, dBは省けます.

結果は有効数字4桁です.

MIPI RFFE

計算のモードで, ビット列からモード, スレーブアドレス, アドレス, データを読み解き, 逆に値からビット列を作ります. rffeと打つと, 使えるモードの例が並びます. 例を選んでEnterを押すと入力欄に入るので, 値を直して使います.

打つもの出るもの
0110010111001001110000(13桁以上のビット列をそのまま. 空白と_は無視)モード(Register Writeなど), SA, アドレス, データ, パリティが合っているか, 区切ったビット列
rffe w 6 1C 38Register Writeのビット列(SA, アドレス, データ. 値は16進)
rffe r 6 1CRegister Read
rffe ew 6 40 12 34, rffe er 6 40 2Extended Register Write, Read(Readの最後はバイト数)
rffe ewl 6 1234 AB, rffe erl 6 1234 2Extended Register Write Long, Read Long
rffe w0 6 38Register 0 Write
rffe 6 1C 38モードを書かなければ, 使えるモードを全部
Excelの表をコピーしてrffeSCLKの列とデータの列(0と1)を, 列ごとに読み解く

クリップボードの履歴

cb と打つと, コピーした文字とファイルが新しい順に出ます. 続けて打つと絞れます. Enterで, 前に使っていたアプリに貼り付けます. Tabでは, コピーだけ(Copy)と, 履歴から消す(Delete from history)を選べます.

  • 覚えるのは200件までで, メモリの中だけに置きます. Hikidashiを終了すると消えます. 画像は覚えません.
  • パスワード管理ソフトなどが「記録しないで」と印を付けたものは覚えません.
  • 使わないときは, 設定のSearchのClipboard historyをオフにします.

選択した文字で開く

ほかのアプリで文字を選び, Ctrl+Alt+Spaceを押すと, その文字を入れて窓が出ます. 2行以上なら, 長い質問の窓に入ります. 選んだパスを開く, 分からない語をChatGPTに聞く, といった使い方ができます. キーは設定のKeysで変えられます.

選んだ文字は, そのアプリにCtrl+Cを送って読みます. ターミナルではCtrl+Cが中断になるので, 送らずに空の窓を出します.

エイリアス

設定のAliasesで, 短い語を打つとアプリ, Webページ, コマンドが開くようにできます.

[alias]
ppt = "PowerPoint"

[[command]]
name = "jira"
title = "Open Jira issue"
url = "https://jira.example.com/browse/{q}"

[[command]]
name = "dot"
title = "Open dotfile in VS Code"
run = 'code "C:\Users\me\project\work\dotfile"'
  • アプリ: pptと打つとPowerPointが出ます. 2行目に何で一致したかが出ます. アプリはexeの名前(winwordなど)でも探せます.
  • urlのコマンド: jira ABC-123と打つと, {q}にABC-123を入れたページを開く行が1位に出ます. 右端はurlです.
  • runのコマンド: 名前を打つと出て, Enterでコマンドを実行します(cmd.exe /cで, 窓は出しません). 右端はrunです.

スクリプトと拡張

スクリプト

%APPDATA%\Hikidashi\scriptsフォルダーに置いた.ps1, .bat, .cmd, .pyが一覧に出ます(フォルダーは自分で作ります). Enterで実行し, 出力が窓に並びます. 行を選んでEnterでその行を, Tabで全部をコピーできます. 30秒で打ち切ります.

ファイルの先頭30行のコメントに, 次のように書けます(どれも省けます).

# @hikidashi.title  空き容量
# @hikidashi.keyword  disk
Get-PSDrive -PSProvider FileSystem | ForEach-Object { "$($_.Name): $([math]::Round($_.Free/1GB)) GB" }
書くもの意味
@hikidashi.title一覧に出す名前. なければファイル名
@hikidashi.keyword打つ語
@hikidashi.argument語のあとに打った文字を, 引数として渡す
@hikidashi.mode list出力を一覧として覚え, 語と空白のあとに打って絞る(keywordが要る)
@hikidashi.refresh 30m一覧を作り直す間隔(30m, 2h)

JavaScriptの拡張

打つたびに答えを出すものは, JavaScriptで足せます. %APPDATA%\Hikidashi\extensionsフォルダーに.jsを置くと, 窓を出すたびに読み直します. 書き方の見本は, リポジトリのextensions/rffe.jsです.

export const meta = { title: "文字数", keyword: "len" };
export function search(query) {
  return [{ title: String([...query].length), subtitle: "文字", copy: String([...query].length) }];
}

ファイルやネットワークには触れません. 1回0.2秒で打ち切ります. metaにcalc: trueを書くと計算のモードでも, clipboard: trueを書くとクリップボードの文字も使えます.

ほかのアプリから開く

Hikidashi.exe --query "kaigi"を実行すると, その文字を入れて窓が出ます. 動いていなければ起動します.

タスクトレイのメニュー

タスクトレイのアイコンをクリックすると, 窓が出ます. 右クリックでメニューが出ます.

設定

タスクトレイのメニューのSettingsか, 入力欄にsettingsと打って出るHikidashi settingsで, 設定画面が開きます. 左で区分を選び, 右で変えるとすぐ反映され, 下にApplied(反映しました)と出ます. 文字を打つ欄は, 打ち終えて離れたときかEnterで反映されます. 間違いのある欄は反映されず, 下に赤く出ます. Hikidashiを起動し直す必要はありません.

設定ファイル

設定は%APPDATA%\Hikidashi\config.tomlに保存されます. 設定画面の左下のOpen config fileでメモ帳で開け, 直して保存するとすぐ反映されます. Copy setup prompt(設定プロンプトをコピー)を押すと, ChatGPTなどのAIに設定を直してもらうための文が, 書き方の決まりと今の設定ごとコピーされます. AIに貼って希望を書き, 返ってきた全文をこのファイルに貼って保存します. 今の設定(フォルダーの場所やWebのアドレス)もAIに渡るので, 貼る前に確かめてください. 初めて起動したときに, 説明のコメント付きで作ります.

探す範囲

ファイルとフォルダーは, 起動したときに一覧(索引)をメモリに作ってから探します. 名前だけを探し, ファイルの中身は探しません.

対象作り直すとき
ユーザーフォルダー(%USERPROFILE%)変更を見張り, 変わってから0.5秒たったら作り直す(ファイルが多いと, 作り直しの間を空ける)
Box(Box Driveの手元のデータsync.dbから読む. フォルダーは見に行かない)Box Driveのデータが変わったとき(最短5分おき). 起動した直後は下にReading Box Drive…
WSLのホームw を打ったとき(前に読んでから5分たっていれば)
アプリ(スタートメニュー, デスクトップのアプリのショートカット, ストアアプリ. スタートアップ, 説明書, Webページ, インストーラーは入れない)スタートメニューかデスクトップが変わったとき
  • AppData, node_modules, .gitなどは索引に入れません(設定のSearchで変えられる). シンボリックリンクとジャンクションの先もたどりません.
  • すぐ作り直したいときは, タスクトレイのメニューのRebuild indexを押します. 終わると, 窓の一番下にIndex rebuilt: 3,667 filesのように出ます.
  • 索引を作っている間は, 窓の一番下にIndexing your folder…などと出ます. 最初の索引ができるまでは, ファイルとフォルダーが出ないことがあります.

入力欄に:statsと打つと, ファイルの件数, 索引とHikidashi全体のメモリ, 最後の検索と表示にかかった時間が出ます. Enterで全部コピーします.

アンインストール

  1. Windowsと一緒に起動するようにしていたら, タスクトレイのメニューのStart with Windowsをオフにします.
  2. タスクトレイのメニューのQuitで止めます.
  3. %LOCALAPPDATA%\Hikidashiと, 展開したフォルダー(gitで入れた人はcloneしたフォルダー)を消します.
  4. 設定と学習も消すなら, %APPDATA%\Hikidashiを消します.

よくある質問

PowerToysからAlt+Spaceを引き継ぐ

PowerToysのランチャー(PowerToys Run)がAlt+Spaceを使っていると, Hikidashiでは登録できません. PowerToysの設定でランチャーをオフにしてから, タスクトレイのメニューのChange hotkey…でAlt+Spaceを押します.

ファイルが出てこない

  • 1文字だけでは, ファイルとフォルダーは探しません. 2文字以上打つか, f で絞ります.
  • 起動した直後は, 索引ができるまで出ないことがあります(窓の一番下にIndexing your folder…などと出ている間).
  • 索引に入れない場所(AppData, node_modules, .gitなど)と, ユーザーフォルダーの外は探しません. 変えるときは設定のSearchで, 探すフォルダーと外すものを直します.
  • 作ったばかりのファイルは, 少しあとに出ます(数千件なら1秒ほど, 数十万件なら数十秒かかることがあります). すぐ出したいときはRebuild indexを押します.

ローマ字で日本語の名前が出ない

ローマ字で日本語を探すのは, 英字を3文字以上打ったときです. 起動した直後は辞書を読んでいるので, 漢字に広げて探すのはそのあとになります.

漢字に広げるための辞書(SKK-JISYO.L)は, ライセンス(GPL)の都合でexeには入れず, 別のファイルとしてZIPに入れています(gitで入れた場合はbin\にあります). Hikidashi.exeと同じフォルダーに置いたまま使います. exeを別の場所に移すときは, 辞書も同じフォルダーに置いてください.

exeの隣に辞書がないとき(exeだけを移した場合など)は, 初めて起動したときにSKKの辞書の公開場所から取ってきます(約5MB. 取ってくる間は窓の一番下にDownloading the dictionary…と出ます). 取れるまでは, ローマ字はひらがなとカタカナにだけ広げます(pawa-→パワーは出ますが, kaigi→会議は出ません).

会社のネットワークなどで取れないときは, 窓の一番下にCouldn't download the dictionary…と出ます. 次に起動したときにもう一度試します. 取れない場合は, ZIPのSKK-JISYO.Lを使うか, 取れるPCでSKK-JISYO.Lを保存し, Hikidashi.exeと同じフォルダーに置いてからHikidashiを起動し直します(タスクトレイのQuitで止めて, もう一度起動します).

動きがおかしいとき

%APPDATA%\Hikidashi\hikidashi.logに, 索引の件数とかかった時間, エラーが残っています. 窓の一番下に赤い文字が出たときも, ここに詳しく書いてあります.
